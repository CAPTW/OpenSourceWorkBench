# PySide6 GUI

Use for GUI shell, widgets, previews, validation surfaces, and report entry
points. Keep PySide6 optional. Route domain work through core and plugin
contracts. Do not call external solvers, Octave, MATLAB, OpenFOAM, CalculiX, or
Gmsh directly from GUI code.
