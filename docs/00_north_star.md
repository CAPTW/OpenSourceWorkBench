# OSW North Star

OpenSolver Workbench v0.1 is an educational and research workbench for
engineering solver workflows. It should make project state, unit choices,
materials, imports, solver setup, post-processing, and validation visible before
any expensive or irreversible action.

OSW is not a clone of MATLAB, ANSYS, Simulink, SolidWorks, CATIA, NX, or Creo.
It must avoid industrial certification claims and focus on transparent open
workflows based on standard/exported formats.
