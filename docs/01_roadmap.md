# OSW v0.1 Roadmap

1. Repository skeleton, CLI smoke checks, and Git safety rails.
2. Core contracts for project schema, units, materials, results, and figures.
3. Plugin/add-in API for importers, solvers, and post-processing.
4. PySide6 shell with project tree, preview panes, and report entry points.
5. Standard geometry and mesh import demos.
6. CalculiX, OpenFOAM template, Cantera, CoolProp, and `.m`/`.mat` demo flows.
7. Golden tests, validation matrix, and release checklist.

Each milestone must remain runnable without commercial software.
