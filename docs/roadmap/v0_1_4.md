# v0.1.4 Next Feature Line

`v0.1.4` is the next feature development line after `v0.1.3rc2` maintenance
items are triaged. It should improve real user workflows while preserving the
preview-first safety boundaries established in v0.1.

OpenSolver Workbench remains educational/research software. It is not a stable
production or industrial-certified solver platform. Users must validate
engineering results independently.

## Purpose

- Start the next feature development cycle after maintenance triage.
- Improve onboarding and tutorial paths for source installs and portable use.
- Make project, plugin, result, field, and report workflows easier to inspect.
- Plan optional solver validation dashboards without making optional solvers
  mandatory.

## Candidate Themes

| Theme | Candidate direction | Guardrail |
| --- | --- | --- |
| Onboarding tutorials | Add task-oriented tutorials for demo project, plugin health, report summary, and result inspection. | Use existing fixtures and avoid commercial software. |
| Project workflow polish | Improve project validation messages, navigation, and common CLI/GUI handoffs. | Keep mutation previewable and explicit. |
| Plugin manager UX | Improve install receipts, rejection messages, local ZIP/folder diagnostics, and trust wording. | No remote plugin marketplace or dependency auto-install unless separately scoped. |
| ResultViewer workflow | Improve table, figure, and catalog navigation for ResultDataset objects. | Keep heavy visualization dependencies optional. |
| FieldViewer workflow | Improve field metadata display and safe rendering diagnostics. | No full solver field parser claim without explicit parser evidence. |
| Report/export quality | Improve report sections, warnings, and reproducibility notes. | Reports must not execute solvers, scripts, or hidden side effects. |
| Optional solver validation dashboard | Summarize installed/missing/pass/fail optional dependency evidence. | Dashboard is evidence display, not certification. |
| VFEA planning | Consider experimental VFEA planning only if explicitly scoped later. | Planning only; no implicit solver accuracy or production claim. |

## Non-Goals

- No MATLAB, ANSYS, or Simulink clone.
- No industrial certification or compliance claim.
- No commercial native CAD direct import.
- No unreviewed automatic execution of scripts or solvers.
- No full OpenFOAM UI or broad solver coverage.
- No mandatory heavy dependencies for base import, CLI smoke, or unit tests.

## Start Criteria

- `v0.1.3rc2` maintenance tasks are triaged.
- Release asset smoke and public-release checklists have owners or issues.
- Live optional validation targets have a documented evidence plan.
- GitHub milestones and issues exist for the selected feature themes.
