# v0.1.3rc2 Maintenance And Revalidation

`v0.1.3rc2` is the maintenance and revalidation line after the public
`v0.1.3-rc1` prerelease. Its purpose is to stabilize release evidence and
improve polish without broad feature expansion.

OpenSolver Workbench remains educational/research software. It is not a stable
production or industrial-certified solver platform. Users must validate
engineering results independently.

## Purpose

- Stabilize the public prerelease after `v0.1.3-rc1`.
- Resolve local hygiene residue and keep duplicate-file warnings clear.
- Automate release asset download smoke where practical.
- Improve release notes, checklists, and public release wording.
- Gather live optional solver evidence from machines that already have the
  optional tools installed.
- Avoid feature expansion unless a critical release blocker is found.

## Candidate Tasks

| Area | Candidate task | Acceptance signal |
| --- | --- | --- |
| Hygiene | Confirm duplicate desktop file hygiene remains clean. | Release gate has no duplicate ` (1)` warning. |
| Asset smoke | Automate release asset download, checksum, manifest, wheel, sdist, and portable ZIP smoke. | Repeatable local command records asset evidence under `artifacts/`. |
| Checklist | Add a post-public release checklist. | Checklist records publish, assets, notes correction, and maintenance follow-up. |
| Portable ZIP | Improve portable ZIP user experience. | README_RUN_FIRST and CLI help remain clear; no installer/signing claims are added. |
| Release wording | Refine GitHub Release wording only if stale or misleading language appears. | Public notes accurately say prerelease, assets attached, unsigned portable ZIP, no MSI, and no bundled solvers. |
| Live evidence | Summarize optional dependency validation evidence. | Evidence report distinguishes installed, missing, passed, failed, and skipped dependencies. |

## Non-Goals

- No broad feature expansion.
- No stable production claim.
- No industrial certification claim.
- No tag retargeting.
- No native commercial CAD direct import.
- No Simulink, `.slx`, or `.mlapp` support.
- No full OpenFOAM UI or broad solver coverage.
- No automatic unreviewed execution of external solvers or scripts.

## Exit Criteria

- Public prerelease state remains accurate and inspectable.
- Release asset smoke is repeatable or explicitly documented as manual evidence.
- Live optional validation evidence is recorded where available.
- Scope and known limitations remain visible in public docs.
- GitHub issues for remaining maintenance work are triaged before moving to
  `v0.1.4` implementation.
