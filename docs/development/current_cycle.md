# Current Development Cycle

Current development version: `0.1.3rc2.dev0`

Base public release: `v0.1.3-rc1`

Maintenance milestone: `v0.1.3rc2`

Feature milestone: `v0.1.4`

Live validation milestone: `live-optional-validation`

## Cycle Purpose

`v0.1.3rc2` is a maintenance, revalidation, and release-polish line after the
public `v0.1.3-rc1` prerelease. It should keep release evidence reproducible
and public docs honest before broader `v0.1.4` feature work starts.

## Primary Goals

- Automate release asset download smoke.
- Keep duplicate hygiene clean.
- Improve portable ZIP user experience and docs.
- Summarize live optional validation evidence.
- Maintain the public release checklist.
- Avoid feature expansion unless a critical release blocker requires it.

## Non-Goals

- No stable production claim.
- No tag creation without a dedicated release gate.
- No MATLAB, ANSYS, or Simulink clone.
- No native commercial CAD direct import.
- No industrial certification claim.
