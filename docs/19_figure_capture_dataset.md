# Figure Capture Dataset

`OSW-FUNC-008_FIGURE_CAPTURE_DATASET` normalizes existing script-run artifacts
into lightweight figure datasets. It does not execute `.m` files, parse `.fig`
files, read `.mat` files, or add an execution path outside `OctaveRunner`.

## Purpose

The feature gives reports and GUI viewers a stable data model for figures and
workspace summaries generated by explicit Octave runs or supplied artifact
directories. It is intentionally artifact-first: OSW records what exists, warns
about what is missing or broken, and avoids reconstructing MATLAB/Octave
graphics semantics.

## Data Model

The figure model lives under `osw.scripts.mscript.figure_dataset`:

- `FigureDataset`: dataset id, source run/script, engine, figures, workspace
  variables, stdout/stderr, diagnostics, warnings, artifacts, and metadata.
- `FigureRecord`: one captured or imported figure/data artifact with image,
  vector, PDF, thumbnail, CSV/data paths, axes, diagnostics, and metadata.
- `AxisRecord`: optional axis labels, limits, legend, and display metadata.
- `WorkspaceVariableSummary`: compact summaries for JSON/CSV-derived variables.

All paths serialize as strings, and every model supports dictionary/JSON
round-tripping without optional plotting or image libraries.

## Artifact Normalization

`osw.scripts.mscript.figure_capture` provides data-only helpers:

- discover figure-like artifacts in a workspace or `OctaveRunResult`;
- classify PNG, SVG, PDF, JPG, CSV, and unknown artifacts;
- create `FigureRecord` objects from individual artifacts;
- create `FigureDataset` objects from artifact paths or Octave results;
- load and save FigureDataset JSON.

PNG/JPG artifacts are treated as raster image paths, SVG as vector paths, PDF as
document figure paths, and CSV as data artifacts. Unknown artifacts produce
diagnostics instead of crashing.

## Workspace Summaries

`workspace_extractor` can summarize simple CSV files and JSON variable-summary
files such as `workspace_summary.json` or `variables.json`. It uses only the
standard library and records row/column counts, headers, shapes, data types, and
small previews where available.

This step does not read `.mat` files. That remains the next functional step.

## OctaveRunResult Handoff

`figure_dataset_from_octave_result()` consumes an existing `OctaveRunResult` and
its collected artifacts. The function preserves source run id, source script,
stdout, stderr, diagnostics, and artifact records. It does not re-run Octave and
does not modify the original script directory.

`mscript-run --capture-figures` runs only through the existing explicit
`OctaveRunner` path, then converts the returned artifacts into a FigureDataset.

## GUI Binding

The Plot Viewer can display a FigureDataset without executing scripts. It lists
figures, shows metadata, renders loadable raster images when PySide6 can read
them, and shows placeholders for missing or unsupported image content.

`ScriptPreviewDialog` can hand a FigureDataset to the Plot Viewer after an
explicit Octave run has completed. Import and preview remain non-executing.

## Report Binding

The HTML report generator can embed FigureDataset figure references, include
source script/run identifiers, and add workspace variable summary tables. Missing
or broken image paths become warnings or links instead of report-generation
failures.

## Plugin Metadata

The built-in `osw.mscript_preview` manifest advertises:

- `figure_artifact_collection`
- `figure_dataset`
- `png_svg_pdf_artifacts`
- `workspace_summary_placeholder`
- `report_embedding`

These are data-conversion capabilities. Plugin discovery and health checks still
do not execute plugin code, Octave, MATLAB, or user scripts.

## CLI

Inspect artifacts in a directory:

```powershell
.venv\Scripts\python.exe -m osw.cli figure-artifacts-inspect tests\fixtures\figures
```

Inspect an existing FigureDataset JSON file:

```powershell
.venv\Scripts\python.exe -m osw.cli figure-dataset-inspect tests\fixtures\figures\sample_figure_dataset.json
```

Create a dataset from a serialized Octave run result:

```powershell
.venv\Scripts\python.exe -m osw.cli figure-dataset-from-run run_result.json --out dataset.json
```

## Security Rules

- Figure inspection never executes `.m` files.
- Import and preview remain non-executing.
- Script execution still requires an explicit `OctaveRunRequest`, CLI
  `mscript-run`, or user action routed through `OctaveRunner`.
- The GUI does not call subprocess APIs directly.
- No MATLAB Engine, Oct2Py, `.mat`, `.fig`, Simulink, or `.mlapp` support is
  added in this step.
- Optional image/plot dependencies are guarded and are not required at import
  time.

## Known Limitations

- No `.mat` reading.
- No `.fig` reading.
- No MATLAB Engine or Oct2Py integration.
- No Simulink, `.slx`, or `.mlapp` support.
- No reconstruction of MATLAB/Octave graphics command history.
- Thumbnail generation is optional and skipped with a friendly diagnostic when
  Pillow is unavailable.
