# CalculiX Cantilever Example

This example is the v0.1 bounded CalculiX workflow:

1. Build or import a small mesh.
2. Assign one isotropic elastic material.
3. Define a fixed support and a force or pressure load.
4. Generate a CalculiX `.inp` input deck.

OSW prepares the input deck only. It does not execute CalculiX from the GUI or
claim nonlinear contact, plasticity, or industrial validation coverage.
