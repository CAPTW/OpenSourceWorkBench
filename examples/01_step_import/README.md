# STEP Import Example

This directory is reserved for small standard/exported geometry preview
fixtures.

The v0.1 CAD import layer supports lightweight metadata previews for:

- ASCII STL surface meshes
- OBJ vertex/face previews
- STEP, IGES, and BREP metadata-only bridge stubs until an optional CAD kernel
  integration is reviewed

OSW v0.1 does not support native commercial CAD direct import. Export STEP or
STL from the source CAD tool before importing into OSW.
